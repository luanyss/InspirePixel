🚀 **Projeto Inspire Pixel - Galeria de Inspiração**
Este projeto foi desenvolvido como parte de um desafio técnico proposto pela escola Vai Na Web. O objetivo foi criar uma galeria de imagens responsiva, moderna e funcional, utilizando as melhores práticas de desenvolvimento Web com o framework Vue.js.

📸 **Demonstração**
Link do Projeto: (https://passoia-mi59.vercel.app/)


🎯 **Requisitos Cumpridos**
Baseado no briefing do desafio, todas as funcionalidades foram implementadas com sucesso:

[x] Consumo de API Externa: Integração com a API Picsum Photos utilizando Axios.

[x] Responsividade Total: Layout adaptável para Mobile (grade de 2 colunas) e Desktop.

[x] Componentização: Estrutura organizada em componentes reutilizáveis (Header, Banner, Card, Footer).

[x] Estilização com Pré-processador: Uso de Sass (SCSS) para um CSS mais limpo e organizado.

[x] Lógica de Favoritos: Funcionalidade de "curtir" fotos com alteração visual de estado.

[x] Dark Mode: Implementação de troca de tema (Claro/Escuro) utilizando variáveis CSS.

[x] Design Fiel ao Protótipo: Alinhamento, cores e ícones baseados no design do Figma.

🛠️ **Tecnologias Utilizadas**
Este projeto utilizou as seguintes ferramentas e tecnologias:

Vue.js 3: Framework principal (Composition API).

Vite: Ferramenta de build para um desenvolvimento rápido.

Sass/SCSS: Para estilização avançada e variáveis.

Axios: Para requisições HTTP e consumo da API de imagens.

Git & GitHub: Para controle de versão e versionamento de código.

Vercel: Hospedagem e Deploy contínuo.

🎨 **Destaques do Desenvolvimento**
Filtros de Cor Dinâmicos: Implementação de filtros CSS (invert, brightness, hue-rotate) para customizar ícones SVG exportados do Figma sem a necessidade de múltiplos arquivos.

Layout Grid & Flexbox: Uso de CSS moderno para garantir que a galeria se ajuste a qualquer tamanho de tela.

Variáveis CSS: Centralização das cores do projeto para facilitar a manutenção do Modo Escuro.

💻 **Como rodar o projeto localmente**

Clone o repositório:

Bash

git clone https://github.com/seu-usuario/inspire-pixel.git
Instale as dependências:

Bash

Rode o servidor de desenvolvimento:

Bash
